# EasyFact — guide de l'artisan (1 page)

> Version de démonstration : toutes les données sont fictives. N'y saisissez pas de vrais clients.

## Commencer
1. Ouvrez le site, cliquez sur **Accès démo** (ou créez un compte de démo).
2. Menu **Prestations** : vérifiez vos prestations et vos prix. Ce sont eux qui seront repris dans vos devis.
3. Menu **Mon entreprise** : vérifiez votre nom, SIRET, adresse, assurance.

## Faire un devis (3 étapes)
1. **Devis → + Nouveau devis** → choisissez le client.
2. **Décrivez les travaux** en une phrase (ex. « remplacer le chauffe-eau, 2 h de main-d'œuvre »).
   Si l'assistant IA est activé, il propose les lignes ; sinon, ajoutez-les depuis votre catalogue.
3. **Vérifiez** : quantités, prix, **taux de TVA** (c'est vous qui le choisissez), cochez la case, **Valider le devis**.

À savoir :
- Une ligne **« À chiffrer »** n'a pas de prix : saisissez-le.
- Une quantité **« À saisir »** n'était pas dans la demande : indiquez-la.
- « Hors catalogue » : la prestation n'est pas dans vos tarifs, mettez votre prix ou supprimez la ligne.

## Obtenir le PDF
Ouvrez le devis → **Télécharger en PDF** → « Enregistrer au format PDF ».

## Corriger un devis déjà validé
Ouvrez-le → **Nouvelle version**. L'ancienne version reste consultable, marquée « remplacée ». Le numéro ne change pas.

## Si quelque chose ne va pas
- **L'IA ne répond pas** : vous passez en saisie manuelle, votre texte est gardé.
- **« Ce devis a déjà été modifié »** : il a été changé dans un autre onglet ; ouvrez la dernière version.
- **Bouton PDF grisé** : il manque un prix ou la TVA.
- Page **Aide** dans le menu, ou demandez à l'équipe EasyFact.
